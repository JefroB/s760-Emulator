# Standalone controls

| Control | Use |
| --- | --- |
| CRT | Shows the original firmware interface. Point and click to select a field or action. |
| VALUE | Changes the field under the firmware cursor. Use dragging, the wheel or the control's arrow keys. |
| Panel buttons and soft keys | Operate the original sampler menus and functions; read their current meanings on the firmware display. |
| Gotek Up/Down/Select | Browse the configured floppy library and insert the selected image. Firmware Disk → Load performs the actual load. |
| OUTPUT LEVEL | Adjusts the emulator's stereo output gain. Enable an output device in Configuration to hear it. |
| INPUT LEVEL | Adjusts recording gain. Choose a supported input device in Configuration first. |
| Configuration gear | Opens Session & disks, MIDI & display, Firmware & media, and Audio categories in a layered dialog. |
| On-screen keyboard | Enable it in MIDI & display. Hold a key to play and release it to stop; external MIDI can also be selected. |
| Quit application | Opens the save/discard quit dialog. Window X opens the same dialog. |

The native CRT/LCD and sampled audio come from the firmware runtime. Selecting
a library image does not by itself load a performance. Firmware Disk/Load and
Sampling screens can mute performance playback: return to Perform Play.

Save session captures a restorable same-build checkpoint. Firmware Disk → Save
and Export disk retain disk changes independently. Applying firmware/audio
settings or restarting replaces the current runtime; save your work first.
