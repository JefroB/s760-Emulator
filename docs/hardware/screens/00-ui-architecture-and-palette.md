# What the screen evidence establishes

The [photographs](index.md) show menu text, fields, softkeys, graphs, popups and the captured selection state. They are suitable references for visible organization and for checking emulator content against a matched state.

Perspective, CRT scan artifacts, camera exposure and color processing prevent these photographs from establishing an exact pixel grid, electrical timing or calibrated hexadecimal palette. Previously proposed 640-by-400/480 hardware timing and exact palette values have been removed. Native rendering geometry is documented separately in the [VDP model](../roland-rfsc16a-vdp-and-display-architecture.md).

A photo showing a particular RAM total, SCSI ID or patch value establishes that captured configuration only. It does not identify SIMM geometry, prove optional-board revisions or establish all firmware defaults. Preserve the source image when measuring a visible feature; label estimates as estimates.
