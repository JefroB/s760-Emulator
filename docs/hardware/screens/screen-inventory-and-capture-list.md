# Screen inventory and further captures

The [catalog](index.md) contains 37 existing photographs: two Disk, five Perform, four Patch, six Partial, fifteen Sample and five System views. This is an evidence inventory, not proof that every reachable menu, modal and error state has been captured.

Before requesting another photograph, name the unresolved visible behavior and check the catalog for a matching state. Record firmware version, mode, navigation steps, selected object and settings. Keep the whole active display visible, preserve the original file and document camera transformations. Do not infer exact timing or calibrated colors from a photo.

For implementation comparisons, capture both sides in matched state and report differences. No inferred layout eliminates the need to validate the rendering it claims to describe.
