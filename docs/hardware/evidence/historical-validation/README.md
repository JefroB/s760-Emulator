# Historical hardware validation records

These ten byte-preserved records retain the scope and limitations of their original experiments. They distinguish firmware storage, vector snapshots and numerical replay from unresolved peripheral and DSP semantics. Their presence does not establish current acceptance or physical hardware behavior. Use the maintained hardware references and backlog for current claims. Original hashes/paths identify the historical run; deleted scratch files are not live dependencies.

Eight other unique product/runtime validation records belong in [testing evidence](../../../testing/evidence/historical-research/README.md). Ninety-four top-level shared JSON records were byte-identical to records already retained under `docs/condensed/validation/` and were not duplicated. The [preservation manifest](../preserved-artifacts-2026-10-21.json) records all eighteen unique source/destination identities.
